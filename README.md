# emg-raspi

腕の筋肉から出る電気信号（筋電）を読み取り、AIで「どの指をどのくらいの力で動かそうとしているか」を推定して、義手を動かすためのプログラムです。
公立はこだて未来大学の学生チームで筋電義手を開発しており、このリポジトリはソフトウェアとAIの部分をまとめています。

## 2つの段階

| 段階 | 内容 | 主な結果 |
|---|---|---|
| ① 指の動きの判別（〜2026年7月） | 2チャンネルの筋電から「安静・人差し指・中指」を判別し、サーボで指を動かす | 正解率 約96%、Raspberry Pi 3B+ で1回 約80〜90ms |
| ② 指の力の推定（2026年10月〜、いま進めている） | 16チャンネルの筋電から、指先の力をリアルタイムに推定する | Raspberry Pi 5 で1回 0.71ms（20msごと、約1万回で遅れ0回） |

## ① 指の動きの判別

```
電極（筋電） → アナログ回路（増幅・ノイズ除去） → Arduino（AD変換）
  → Raspberry Pi（CNNで判別） → Arduino（サーボを制御） → 義手の指
```

工夫したこと

- **日を変えると正解率が53%まで落ちた**：隣り合う指の筋肉を区別しにくい電極の位置が原因でした。配置を見直し、95〜96%まで改善しました。
- **判別に1秒以上かかった**：LSTMを使ったモデルは Raspberry Pi では遅すぎたため、CNNだけの軽いモデルに変えて約80〜90msにしました。

## ② 指の力の推定（いま進めている）

つまむ動作で細かい力加減ができる義手を目指し、筋電から指先の力を推定しています。

- **モデルの比較**：公開データ putEMG-Force（3人分）で、ridge・ESN・LSTM・CNN+LSTM・Transformer を比べました。同じ日のデータではどれも大差がなく、大きなモデルにしても精度は上がりませんでした。
- **電極を付け直したときの問題**：電極を付け直した翌日は、そのままでは使えないほど精度が落ちます（相関 r 0.2〜0.4）。4分間だけ記録して学習し直す方法（校正）を比べ、CNN+LSTM 全体を微調整すると r 0.78 まで戻ることを確かめました。
- **今の案（v1）**：CNN+LSTM・16チャンネル。付け直したら4分記録 → CNNの部分を固定して約20秒で学習してすぐ使い始め、裏で全体を微調整して差し替えます。
- **遅れの目標**：力を入れようとしてから指先に力が出るまで **100ms以内**。先行研究（Farrell & Weir 2007 など）をもとに決めました（`docs/latency_target.md`）。

## ハードウェアの選定（いま進めている）

- **AD変換器（ADC）**：5本の指を扱うには筋電のチャンネルを増やす必要があり、Arduino では足りません。生体信号向けのADC（TI ADS1299）を2つ載せた Raspberry Pi 用ボード **PiEEG-16**（16チャンネル）を使う方向で、モデルもこの16チャンネルに合わせています。
- **電極**：皮膚の信号を電極の真上で受け直す「アクティブ電極」（OPA320）を設計し、製作はメンバーに引き継ぎました（`docs/active_electrode.html`）。
- **モーター**：推定した力を UART で STM32（B-G431B-ESC1）に送り、FOC制御でブラシレスモーター（GB2806）のトルクを制御する方針です。

## フォルダ構成

- `collect_data/` : 筋電の収集（Arduino ADC）
- `train/` : 動作分類モデル（ESN / RNN）の学習
- `control/` : リアルタイム制御（推論 → Arduino / STM32）
- `models/` : 動作分類の学習済みモデル
- `force_estimation/` : 筋電による指の力（把持力）の推定。putEMG-Force でのモデル比較・校正実験、ラズパイ5での推論・校正（詳細は `force_estimation/README.md`）
- `docs/` : 報告書・資料（作業報告、遅れの目標の根拠、アクティブ電極の作り方）

## 注意

電極を体に付けて試すときは、PiEEG とつながっている機器をすべてバッテリー駆動にし、コンセントから切り離してください。
