アクティブ電極の作り方

銀板の電極の真上に、オペアンプ OPA320 のバッファを載せます。皮膚の信号をその場で受け直してからケーブルに送るので、ケーブルで拾うノイズを減らせます。部品は OPA320、1kΩ 抵抗、0.1µF コンデンサで、電極1個あたり約10 mm 角の小さな基板にまとめます。

使う部品：OPA320（SOT-23・5ピン）、ROHM ESR18EZPD1001（1kΩ・1206・耐サージ）。PiEEG-16 の入力につなぐ前提です。

01なぜ電極にバッファを付けるのか

皮膚と電極の間はインピーダンスが高く（数十kΩ〜数MΩ）、そのままケーブルを引き回すと、ケーブルの揺れや周りの電気のノイズを拾いやすくなります。電極のすぐ上で電圧フォロワ（増幅率1倍）を通すと、ケーブルを低いインピーダンスで駆動できるため、ノイズが入りにくくなります。

02回路（電極1個分）

OPA320 の 1番（OUT）と 4番（−IN）をつなぐと、増幅率1倍のバッファになります。電極は 1kΩ を通して 3番（+IN）へ入れます。

なぜ抵抗を +IN 側（皮膚と IC の間）に付けるのか

R1 の目的は、皮膚と IC の間に流れる電流を制限することです。静電気や異常な電圧が電極に来たとき、電流は皮膚 → +IN → IC の中の保護ダイオード → 電源、と流れます。抵抗が出力側にあると、この経路には何もないので、IC も体も守れません。逆に IC が壊れて +IN が電源につながってしまったときも、R1 があれば体に流れる電流を制限できます。

OPA320 の入力にはほとんど電流が流れない（入力バイアス電流はピコアンペア級）ので、1kΩ を入れても信号は弱まりません。1kΩ が出す雑音（約 4 nV/√Hz）も、筋電の大きさ（数十µV〜数mV）に比べて無視できます。R2（出力側）は、ケーブルによる発振を防ぐための別の目的の抵抗で、R1 の代わりにはなりません。

部品の役割

  • R1（1kΩ）：静電気や故障時に、体と IC の間に流れる電流を制限します。耐サージ品の ESR18 はこの用途に合っています。
  • C1（0.1µF）：電源のノイズ対策で必須です。今の部品リストにないので追加してください。
  • R2：長いケーブルは容量になり、バッファが発振することがあります。値はデータシートの容量性負荷の項目で確認します。迷ったら 1kΩ をもう1つ使います。

03構造：銀板の上にどう載せるか

部品を銀板の上に直接置くと、ピンどうしが銀板を通してショートします。銀板と部品の間に小さな基板（絶縁）を挟み、銀板は基板の裏側のパッドにはんだ付けして R1 につなぎます。

基板を作る場合（おすすめ）

  • 両面基板、約10×10 mm。上面に部品、裏面全体を銀板用のパッドにします。
  • 裏面パッドはビアで R1 の片側につなぎます。
  • 出力・電源の3本の線は、基板の端のパッドから出します。

基板なしで作る場合（試作1個目向け）

  • 銀板の上にカプトンテープを2〜3重に貼り、その上に部品を接着します。
  • 細い線（UEW 線など）で空中配線し、銀板は端に1か所だけはんだ付けします。
  • ショートと断線が起きやすいので、動作確認用にとどめます。

04基板の配置（上から見た例）

部品は3〜4個なので、10 mm 角に収まります。1206 の抵抗は 3.2×1.6 mm、SOT-23 は 約2.9×2.8 mm です。

05バンド全体の配線

電極1個から出る線は OUT・V+・V− の3本です。1本のバンドの8個は V+ と V− を共通の線にでき、OUT だけがそれぞれ PiEEG の入力チャンネルに行きます。肘側と手首側の2本で16チャンネルです。

  • 参照電極（SRB）：各チャンネルはこの電極との差を測ります。同じバッファ付きにすると、全チャンネルと条件がそろいます。
  • BIAS 電極：体の電位を PiEEG の基準に合わせる電極です。バッファは付けず、銀板を PiEEG の BIAS 出力に直接つなぎます。骨の上など、筋肉の少ない場所に貼ります。
  • バンドの中で V+・V− を共通にすると、電極からの線は「共通2本＋OUT 8本」になります。

07作る手順

  1. PiEEG 側を確認する回路図で、ADS1299 のアナログ電源（AVDD・AVSS）の電圧、BIAS の電圧、入力・SRB・BIAS の端子を確認します。OPA320 はこの AVDD・AVSS と同じ電源で動かすのが安全です（OPA320 の電源範囲は 1.8〜5.5 V）。
  2. 回路図と基板を作るKiCad などで電極1個分を設計します。部品を配置したら、OUT（1番）と −IN（4番）がつながっているか、C1 が IC のすぐ横にあるかを確認します。
  3. まず1個だけ組み立てる部品をはんだ付けし、裏面に銀板をはんだ付けします。まだ封止しません。
  4. 机の上で動作を確かめる（体には付けない）電源を入れて、OUT の電圧が +IN と同じになるか、OUT が発振していないかをオシロスコープで見ます。信号発生器の小さな正弦波（例：100 Hz）を入れて、同じ波が出てくるかも確認します。
  5. 銀板を塩化銀にする食塩水での電気分解か、塩素系漂白剤に漬ける方法で、皮膚に触れる面を塩化銀にします。はんだ付けの後に行います（塩化銀の面ははんだが付きにくいため）。
  6. 封止する部品とはんだの部分をエポキシなどで覆い、汗が入らないようにします。皮膚に出るのは銀板の面だけにします。
  7. 2〜3個で腕に付けて比べる今のパッシブ電極と並べて筋電を記録し、ノイズの大きさを比べます。このときの電源の条件は、下の安全の項目を守ります。
  8. 残りを作る問題がなければ、16個＋参照1個を作り、2本のバンドに取り付けます。

08確認すること

机の上で

  • 電源を入れても IC が熱くならない
  • OUT の電圧が +IN と同じ（数 mV 以内）
  • OUT に高い周波数の発振が出ていない（ケーブルをつないだ状態で）
  • 入力した正弦波が同じ大きさで出てくる

腕に付けて

  • 力を抜いたときのノイズが、パッシブ電極より小さい
  • 指に力を入れると、その電極の筋電が大きくなる
  • ケーブルを揺らしても波形が大きく乱れない
  • PiEEG の入力が振り切れていない（振り切れたらゲインを下げる、例：4〜8）
ゲインについて

バッファは直流もそのまま通します。電極ごとに直流の電位が違うと、ADS1299 のゲインが高い設定では入力が振り切れることがあります。最初はゲインを低めにして始めます。

安全：電極を体に付けるときは必ず守る

PiEEG・ラズパイ・ノートPC・モニターなど、電極とつながっている機器はすべてバッテリーで動かし、コンセントから完全に切り離します。ノートPCも充電器を抜きます。R1 の 1kΩ は補助的な保護で、安全の基本はこの電源の分離です。体に付ける回路は、使う前に教授や担当の先生にも確認してもらいます。

09まだ決まっていないこと

  • PiEEG-16 の AVDD・AVSS と BIAS の電圧（OPA320 の電源をどこから取るか）
  • R2 の値（ケーブルの長さと OPA320 のデータシートで決める）
  • 銀板の大きさと形、基板を発注するか手作りするか
  • ケーブルの種類（シールド線にするか）と、バンドへの固定方法
